# WhatsApp-чат на GREEN-API

Тестовое задание на позицию «Фронтенд-разработчик React»: веб-чат для текстовых сообщений WhatsApp через GREEN-API, внешний вид по мотивам web.max.ru.

- Репозиторий: https://github.com/litvnvdev/green-api-testovoe
- Демо: https://green-api-testovoe-murex.vercel.app/ (деплоится из `main`)

Ниже — кто что сделал. Работа шла в паре: Максим ставил задачи, принимал решения и проверял результат на реальном инстансе, Claude (Claude Code) писал код, тесты и документацию.

2. Создал репозиторий на GitHub и попросил пушить работу последовательно, по коммиту на шаг.

6. Поставил задачи на доработку:

8. По ходу рефакторинга добавил требования: лоадеры между страницами и при запросах, TanStack Query вместо ручных `useEffect`, статусы сообщений «прочитано / не прочитано» — отдельными коммитами.

### Рефакторинг (PR #1, ветка `refactor/fsd`)

1. Инструменты: алиас `@/`, переадресация всех путей на `index.html` для Vercel, steiger в `npm run lint`.
2. FSD:
   - `ChatContext` разделён на `entities/session`, `entities/chat` и `entities/message`;
   - пять фич, два виджета, три страницы;
   - у каждого слайса свой public API.
3. Zod:
   - схемы для ответов API, вебхуков, кредов, номера и данных из `localStorage`;
   - все типы выводятся через `z.infer`;
   - схема сообщения собрана из схемы события API.
4. React Router 8: защищённые маршруты, `/chat/:phone`, возврат на нужную страницу после входа.
5. React Hook Form с `zodResolver` и общий `TextField`.
6. Фавикон (SVG, ICO, apple-touch-icon) и `site.webmanifest`.
7. TanStack Query:
   - вход и отправка — мутации;
   - настройки инстанса — запрос, который повторяется при возврате на вкладку;
   - токен не попадает в ключи запросов.
8. Лоадеры: ленивые страницы, полоса прогресса при переходах, спиннеры.
9. Статусы доставки и прочтения:
   - вебхук `outgoingMessageStatus`;
   - статус никогда не откатывается назад (`mergeStatus`);
   - отметки-галочки как в мессенджерах.
10. На каждом шаге: сборка, линтер, steiger и тесты (45 штук); проверка в браузере; обновлённые README и скриншоты.

## Для следующих сессий Claude

- **Команды:** `npm run dev`, `npm run build`, `npm run lint` (ESLint, Prettier, steiger), `npm test`. Нужен Node 22.22+.
- **Архитектура:** FSD.
  - Импорты между слайсами — только через `index.ts`.
  - Импорт между сущностями — через `@x` (`entities/message/@x/chat.ts`).
- **Типы и валидация:** новые типы данных заводим как Zod-схему и выводим тип через `z.infer`, а не описываем интерфейс вручную.
- **Коммиты:**
  - по одному на шаг, каждый с зелёными проверками;
  - сообщения в стиле Conventional Commits;
  - крупные изменения — в отдельной ветке через PR, потому что `main` сразу деплоится на Vercel.
- **Тестирование:**
  - реальных кредов GREEN-API в репозитории и в чате нет;
  - проверка в браузере — на подменённом `fetch`;
  - сквозной сценарий с телефоном проверяет Максим.
- **Настройки инстанса**, без которых не работает получение: `incomingWebhook` и `outgoingWebhook` включены, `webhookUrl` пустой.
